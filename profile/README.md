### What we do
- **Consulting** — red teaming, application security, attack-surface monitoring, zero-day
  research, enterprise security, AI agent security.
- **PAVE** — our Program Analysis and Verification Engine: builds a semantic model of your
  software and proves findings during analysis.

### Responsible disclosure
Vulnerability reports go to **research@phinode.io** — encrypt with our PGP key. We coordinate
disclosure and never publish operational exploit detail before a fix is public.
